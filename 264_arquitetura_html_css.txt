ESTRUTURA DE CAMADAS E LAYOUT (O MACETE DO STICKY)
- Regra de Ouro do Scroll: NENHUM elemento (`html`, `body`, `.scroll-shell`, etc) até chegar no stage pode ter `overflow: hidden`, `overflow: auto`, `transform`, `filter`, `perspective`, ou `contain: paint`. Isso mata o `position: sticky` nativo[cite: 17].
- `.scroll-shell` (Wrapper Geral): É o recipiente de rolagem alto. `position: relative`, `height: 430vh`, `min-height: 2800px`, `background: var(--paper)`[cite: 17].
- `.sticky-stage` (O Palco Visível): `position: sticky; top: 0; width: 100%; height: 100vh (ou 100svh); display: flex; align-items: center; justify-content: center; overflow: hidden; isolation: isolate;`[cite: 17]. Apenas o palco usa overflow hidden para cortar a Headline exagerada.
- Camadas (Z-Index):
  1. `z-index: 1`: Headline Background (Fantasma)[cite: 17].
  2. `z-index: 3`: Headline Foreground (Verde, as letras esmaecem individualmente)[cite: 17].
  3. `z-index: 4`: Container de Cards (`.cards`)[cite: 17].
  4. `z-index: 5`: Header Label[cite: 17].
  5. `z-index: 6`: Progress Pill[cite: 17].
- Layout da Headline: Centralizada, `position: absolute; inset: 0`, flex column. Textos em `Cormorant Garamond`, peso 300, `font-size: min(10.6vw, 28vh)`, `line-height: .9`, `text-transform: uppercase`, `white-space: nowrap`[cite: 17].
