GLOBAL STYLES & TOKENS
- Resets Obrigatórios: * { box-sizing: border-box; } html { font-size: 62.5%; } html, body { margin: 0; min-height: 100%; } 
- A página utiliza pesadamente valores em `rem`. O scale de 62.5% no html permite que 1rem = 10px. Em telas <=834px, alterar para `html { font-size: 56.25%; }` para escalar toda a UI.
- Tokens de Tipografia:
  --font-display (Títulos principais estilizados/Serif)
  --font-ui (Labels e elementos de interface/Sans)
  --font-body (Textos longos/Sans legível)
  --font-button (Botões)
- Tokens de Cores (Injeção Dinâmica):
  --color-primary (Acento principal, ex: Neon)
  --color-primary-hover
  --color-secondary
  --color-accent
  --color-background (Fundo escuro profundo)
  --color-text
  --color-text-soft (Muted)
  --color-surface (Fundos translúcidos de cards)
  --color-surface-border
- Sombras e Brilhos:
  --shadow-strong
  --shadow-button
  --color-glow-soft
- Regra de Arquitetura: Plain HTML, CSS e Vanilla JS. Proibido o uso de frameworks. APIs do navegador exigidas: IntersectionObserver, matchMedia, requestAnimationFrame, Pointer Events.
